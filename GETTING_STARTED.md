## 💡 Key Features to Know

### Category Filtering
Click any category button on the homepage to filter posts. The system dynamically loads content based on your selection.

### Affiliate Disclosure
Every page includes clear affiliate disclosure - both in the footer and on individual post pages. This builds trust with your readers.

### Product Integration
Each blog post contains 8-15 Amazon affiliate product recommendations, naturally integrated into the content. Product links are styled subtly with hover effects.

### Related Posts
Each blog post page automatically displays 3 related posts from the same category (or similar topics if fewer are available).

### Newsletter Signup
Newsletter forms appear on every page. When submitted, they show a confirmation message (you can integrate with your email service later).

## 💬 Support & Customization

### Want to Change Colors?
Edit the `:root` CSS variables in `css/style.css` (lines 10-17)

### Want to Add More Posts?
Use the RESTful Table API to add new posts with the same structure

### Want to Change Layout?
Modify `css/style.css` - all styles are well-organized and commented

### Want Different Fonts?
Update the Google Fonts import in HTML files and change font variables in CSS
